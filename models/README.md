# Model code

| Directory | Model |
|---|---|
| onelayer_10-random-seeds/ | One-hidden-layer comparison model |
| twolayers_10-random-seeds/ | Two-hidden-layer model |
| ablation_10-random-seeds/ | Meaning-only and sound-only variants |

All batch launchers use seeds 7, 42, 88, 123, 200, 314, 456, 555, 789, and 999.
Run commands from the repository root.

## Training and evaluation

Inputs are data/processed/word_centric_dict.json and the two tensors in
data/embeddings/. Training writes .pth states below each variant's weights/
directory. Evaluation reads those states and writes per-epoch CSVs below
checkpoint/.

For one two-layer run:

    python models/twolayers_10-random-seeds/training/train_twolayers.py --hidden_dim 22 --epochs 25 --seed 42
    python models/twolayers_10-random-seeds/evaluate_twolayers.py --hidden_dim 22 --seed 42

For all ten seeds at dimension 22:

    bash models/twolayers_10-random-seeds/training/train_twolayers_all.sh 22
    bash models/twolayers_10-random-seeds/eval_twolayers_all.sh 22

Omitting the dimension argument runs the configured dimension grid. Set
DRY_RUN=1 to print commands. Launchers default to sequential execution.
For a configured SLURM cluster, set SUBMIT_TO_SLURM=1 and the resource options
near the start of the launcher. PYTHON selects the interpreter.

## Complete logits and relative measures

    python models/twolayers_10-random-seeds/extract_full_logits.py --seed 42

Extraction requires the trained state and its reference evaluation CSV. After
generating all ten complete-logit archives, compute the relative measures:

    python models/twolayers_10-random-seeds/compute_logit_measures.py --output_dir data/logit_measures_rebuilt

The separate output directory preserves the supplied canonical measures.
Compare results before replacing model measures and rebuilding trial inputs.

Trained states, evaluation CSVs, and complete-logit arrays are generated by these
upstream workflows. They are not included in this archive; downstream analyses
use the supplied processed measures and summaries.
